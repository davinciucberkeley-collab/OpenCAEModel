## 5. Non-blocking (concrete fixes)

1. **Intermittent hang in the window tests.** The first full run stalled with no output for more than 12 min, probably in
   `test_screenshot_drone_mode` (QtWebEngine). Add `pytest-timeout` (for example `timeout = 300` in
   `[tool.pytest.ini_options]`) so a hang fails instead of blocking CI. Give the WebEngine screenshot test an explicit
   wait with a deadline (`QTest.qWaitFor(..., 20000)`) rather than an open-ended load wait.
2. **Green headline numbers on estimates.** `dash.css` `.big.ns-ok` with `dash.js:320` colours "472 g", "6.6 : 1" and
   "12.24 x" green under an amber "Conditional" pill (v2_results.png). Green next to a number reads as "verified"
   (C2). Colour the number from `numeric_status` only when `status` is not `conditional`, or use neutral text with a
   small coloured marker.
3. **No range checks on physical inputs.** A same-origin POST `{"propulsion.motor.kv": -5}` returned 200 and was
   saved. `run --only propulsion` then gave `fail` with "each rotor pulls 0.0 N". That outcome is safe, but the
   message is misleading. In `spec.validate`, reject values ≤ 0 for kv, diameter, cells, capacity, density, modulus
   and yield, and outside (0, 1] for efficiency and usable_fraction. The existing "red and file unchanged" path then
   covers it.
4. **`/k09l/` GETs skip the Host check** (server.py:495-500 run before :501). A DNS-rebinding page could read the K09-L
   static dashboard. This is low impact, because no write is possible. Move the `_host_ok()` check above the `/k09l`
   branch, or apply it to every GET.
5. **Saw-toothed slice edges** (fix_contour_cp_slices.png). `_flow` crops with `extract_cells(keep)` on whole cells.
   Clip with `sl.clip_box(bounds, invert=False)` before triangulating, so the slice edges are straight.
6. **Cancelling on Windows/WSL.** `kill_tree` on the WSL route ends `wsl.exe`. Also run `wsl -e pkill -f <case dir>`,
   or have `inst.argv` write a pid file and kill that pid, so simpleFoam does not keep running after Stop.
7. **One compare.** dash.js still builds compare rows from metrics and only borrows `better`. Store `iterate()`'s
   `compare` in the variant's results.json and render it, or drop `compare` from `iterate()`.
8. Left over from R1, still valid: N1 (one shared input reader for cfd/structure/flight), N3 (state V_CELL and the rho
   fallback, write the template defaults as `status: user`) and N9 (`ROLE_NEEDS` vs structure, see C5).
9. The server's geometry cache stamp (server.py `geometry()`) leaves out the CAD file. Replacing `airframe.stl` without
   touching drone.json serves the old model until a run. Add `self.project_dir / spec["geometry"]["file"]` to `files`.

## 6. Could it be simpler, could anything be removed?

- `cfd.py:529` passes `math.pi - al` so that `_cfd_post`'s hard-coded (cos a, 0, sin a) comes out right. It is correct,
  but it is a trick tied to a K09-L internal. Give `_cfd_post` a `flow_dir` argument (default: the old formula) and
  pass `drag_d`.
- `pipeline._conditional_on_estimates` (pipeline.py:121-136) finds "estimate" by splitting basis strings on commas and
  spaces. Use `T.ESTIMATE in basis` with the shared weakest-basis helper (R1 N1), and the string parsing goes away.
- `server.field()` re-implements the shared-mesh lookup that `cfd.load_surface_field` already does. Call
  `load_surface_field` after the `_FIELD_RE` check, and drop the duplicate (about 10 lines).
- `pipeline._run_k09l` (pipeline.py:~437) keeps an inline copy of the old permissive sanitizer, next to the new
  `variant_name`. Use one function.
- There are now two label systems: `workspace.LABELS` (30 entries, "Motor KV") in the app, and `niceKey`
  ("motor / kv") in the dashboard. The same key gets different names in the two views of one file. Either serve
  `friendly_label` through `/api/project` and use it in both, or (R1 N12) drop the Qt parameter sheet and keep only
  the dashboard tab. The second removes about 190 lines.
- `server.geometry()` calls `variant_dir` twice. The first call is only a validity check. Keep one.
